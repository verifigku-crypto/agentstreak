AgentStreak

A daily check-in streak for Agent ID holders. One check-in per UTC day — miss a day and the streak restarts at 1.

How Agent ID is used

AgentStreak only works if your wallet holds an Agent ID — an on-chain name issued to an Agentic Wallet. Every check-in calls balanceOf on the Agent ID contract; if your balance is zero the transaction is rejected on-chain. Your Agent ID is never stored, copied, or sent anywhere by this page — the check happens entirely inside the smart contract. No login, no QR code, no session, no seed phrase, no private key is ever asked for or collected.

AgentStreak is a free daily check-in experiment. It promises no rewards, tokens, points value, or returns of any kind.
